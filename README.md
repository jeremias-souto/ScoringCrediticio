# Scoring Crediticio
Este es un pequeño y simple sistema que utilizan los bancos y las entidades financieras para evaluar el riesgo y decidir si otorgar o no un préstamo a una persona.

# Tecnologias usadas
-HTML

-CSS

-JS

-QUnit

# Conocimientos aplicados
-POO

-TDD (con QUnit)

-Redes neuronales simples (neurona de McCulloch-Pitts)

# Como probar la app?
-Descarga el repositorio

-Abre el archivo "index.html"
